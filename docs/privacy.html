Politique de confidentialité

Dernière mise à jour : 27 novembre 2026.

Qui utilise l'outil

586 Ai Studio est utilisé uniquement par le titulaire du compte TikTok @586ai1, pour son propre compte.

Données utilisées

  • Identifiant de compte TikTok et jeton d'accès accordés par le créateur via « Se connecter avec TikTok ».
  • Les vidéos créées par l'outil, envoyées sur le compte du créateur.
  • Statistiques publiques des vidéos du créateur (vues, abonnés gagnés) pour améliorer les vidéos suivantes.

Conservation et sécurité

Les jetons sont stockés chiffrés dans les secrets GitHub Actions du créateur, jamais dans le code ni dans un fichier public. Aucune donnée n'est vendue, partagée ou utilisée à des fins publicitaires.

Retrait

Le créateur peut révoquer l'accès à tout moment depuis TikTok (Paramètres → Sécurité → Applications autorisées).

Privacy policy (English)

This tool is used only by the owner of TikTok account @586ai1 for that account. It stores the OAuth token in encrypted GitHub Actions secrets, uploads videos the owner created to the owner's account as private posts, and reads the owner's video statistics. No data is sold or shared. Access can be revoked at any time in TikTok settings.
